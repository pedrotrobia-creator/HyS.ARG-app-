## ✅ Opciones de respuesta estándar

- **C** → CONFORME
- **NC** → NO CONFORME
- **O/M** → OBSERVACIÓN / MEJORA
- **NA** → NO APLICA
- **NSV** → NO SE PUDO VERIFICAR

**Prioridad de corrección:** CRÍTICA → ALTA → MEDIA → BAJA → A DETERMINAR
